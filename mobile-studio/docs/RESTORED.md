# Recovery of useful legacy capabilities

Original Pocket Sample remains intact in its own Site and archive branch. This is selective restoration in a mobile workflow, not full feature parity or Akai firmware emulation.

| Use | Restored in mobile Studio | Location |
| --- | --- | --- |
| Play a sample as an instrument | Scale/chromatic touch keyboard, MIDI keys, held notes | Séquence → Clavier |
| Write/edit melody and chords | Piano roll, note timing/pitch/duration/velocity, copy/delete, zoom | Séquence → Notes |
| Keep or correct playing feel | Free/grid recording, partial quantization | Notes → Aligner |
| Develop a loop | Duplicate, double with notes, shorten, reverse track | Séquence → Boucle |
| Turn a mix into reusable sound | Render loop with FX and tails into an empty pad | Séquence → Boucle |
| Clean/exchange samples | Crop selected stereo audio with undo, raw selected WAV | Son → Découpe |
| Transform a sample | Pitch, envelope, stereo pan, choke, 50–200% time stretch | Son → Réglages |
| Process individual/mixed sound | Two targeted FX slots per pad and two Master slots, catalog, XY | Effets |
| Record real sound | Explicit temporary take and review before keep | Micro |
| Play/control other gear | MIDI ports/channels/notes/clock; physical validation still needed | MIDI |

## Larger capabilities still separate

- A true Song/arrangement view for ordering multiple loops.
- Effect/parameter automation and temporal performance effects.
- 16 Levels and a broader set of scale/keyboard layouts.
- Independent loop-start markers, advanced warp preparation, threshold-triggered sampling and richer input-device controls.
- Larger sequence capacity, complete old-project migration, native mobile MIDI/audio integration.

These need dedicated interaction design and validation. They have not been silently claimed as restored. Four main destinations remain useful for the current set; a future Song workflow may justify another destination.
