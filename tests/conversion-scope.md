# Périmètre réel de la conversion

Source de la cible : [guide officiel MPC Sample 1.3.0, pages 24–63](https://cdn.inmusicbrands.com/akai/sample/MPC%20Sample%20-%20User%20Guide%20-%20v1.3.0%20(RevA).pdf).

| Ensemble | État |
|---|---|
| Granulateur | Cœur reconstruit, tests numériques finis ; adaptation navigateur et APK de laboratoire |
| Sample Delay stéréo | Boucle reconstruite et comparée sur 1 600 blocs ; intégrée aux commandes de test ; liaison des réglages/automation originale non vérifiée |
| Autres Pad FX | Pas convertis : Half Speed, Chorus, Flanger, Phaser, Comb Filter, LP/HP/BP Filter, Ring Mod, LoFi, Color, Beat Repeat, Rev Stepper, Delay, Reverb |
| Autres Knob FX | Pas convertis : autres délais, réverbérations, filtres, dynamique, saturation, modulation et émulation vintage |
| Flex Beat | Pas converti |
| Compresseur dédié / Color | Pas converti |
| Lecture de samples et enveloppes originales | Pas reconstruites ; la page emploie Web Audio |
| Séquenceur / Song Mode / automation / MIDI | Pas de portage du moteur original ; séquenceur simple indépendant présent |
| Formats de projets Akai | Compatibilité non réalisée ; fichiers Pocket Sample propres à la démo |
| iOS | Pas construit |

L’interface, le découpage et les pads de la démo ne prouvent pas une conversion de ces modules Akai. Le test navigateur et l’APK ne constituent pas la conversion complète. Le manuel confirme pour le granulateur une durée de 10–200 ms, une densité de 1–300 grains/s et un feedback de 0–100 % ; les limites des commandes de test ont été alignées sur ces valeurs.
